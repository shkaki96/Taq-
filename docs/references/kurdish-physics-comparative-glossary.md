# فەرهەنگۆكا بەراوردكاری یا چەمكێن فیزیا (Comparative Kurdish Physics Glossary)
## English - Arabic - Badînî (بادینی) - Soranî (سۆرانی) - Kurmancî (KMR)

ئەم خشتەیە بەراوردییە یا زاراوە و چەمکێن فیزیایی یە ژ سەرچاوەیێن فەرمی یێن پڕۆگرامێ خاندنێ ل هەرێما کوردستانێ، بەهدینی، سۆرانی و لاتینی.
