# پڕۆگرامی فەرمیی فیزیای پۆلی یازدەهەمی زانستی - هەرێمی کوردستان (سۆرانی / CKB)
## Physics Grade 11 Complete Curriculum Reference - Kurdistan Region

**سەرچاوەی فەرمی**: کتێبی فەرمیی فیزیا بۆ پۆلی یازدەهەمی زانستی (وەزارەتی پەروەردەی حکومەتی هەرێمی کوردستان - زانست بۆ هەمووان).
پڕۆگرامەکە پێکدێت لە **٨ بەشی سەرەکی** بە تەواوی یاساکان، هاوکێشەکان، پاشکۆی هێماکان، یەکەکان، نەگۆڕە فیزیاییەکان و فەرهەنگی پێناسە زانستییەکان.

## بەشی دووەم: یاسا، هاوکێشە و پەیوەندییە بیرکارییە فەرمییەکان (پاشکۆی هـ)

### ١. هاوکێشەکانی جووڵە لە یەک دووریدا (بەشی ١)
* **لادان**: $\Delta x = x_f - x_i$
* **ناوەندە خێرایی**: $v_{\text{avg}} = \frac{\Delta x}{\Delta t} = \frac{x_f - x_i}{t_f - t_i}$
* **ناوەندە تاودان**: $a_{\text{avg}} = \frac{\Delta v}{\Delta t} = \frac{v_f - v_i}{t_f - t_i}$
* **هاوکێشەکانی جووڵە بە تاودانی نەگۆڕ لەسەر هێڵی ڕاست**:
  $$\Delta x = \frac{1}{2}(v_i + v_f)\Delta t$$
  $$\Delta x = v_i \Delta t + \frac{1}{2}a (\Delta t)^2$$
  $$v_f = v_i + a\Delta t$$
  $$v_f^2 = v_i^2 + 2a\Delta x$$

### ٢. هاوکێشەکانی جووڵە لە ڕووتەختێکدا و هاوێژراوەکان (بەشی ٢)
* **تیۆرمی فیساگۆرس**: $c^2 = a^2 + b^2 \implies c = \sqrt{a^2 + b^2}$
* **نەخشە سێگۆشەییەکان**: $\sin\theta = \frac{\text{بەرامبەر}}{\text{ژێ}}, \quad \cos\theta = \frac{\text{تەنیشت}}{\text{ژێ}}, \quad \tan\theta = \frac{\text{بەرامبەر}}{\text{تەنیشت}}$
* **جووڵەی شاوڵی (کەوتنی سەربەست)** ($a_y = -g = -9.81\text{ m/s}^2$):
  $$v_{y,f} = a_y \Delta t, \quad v_{y,f}^2 = 2a_y \Delta y, \quad \Delta y = \frac{1}{2}a_y (\Delta t)^2$$
* **جووڵەی ئاسۆیی هاوێژراو**: $v_x = v_{x,i} = \text{نەگۆڕ}, \quad \Delta x = v_x \Delta t$
* **هاوێژراوی بە گۆشە هاوێژراو**:
  $$v_x = v_i \cos\theta, \quad \Delta x = (v_i \cos\theta)\Delta t$$
  $$v_{y,f} = v_i \sin\theta + a_y \Delta t$$
  $$v_{y,f}^2 = v_i^2 (\sin\theta)^2 + 2a_y \Delta y$$
  $$\Delta y = (v_i \sin\theta)\Delta t + \frac{1}{2}a_y (\Delta t)^2$$
* **جووڵەی ڕێژەیی**: $\vec{v}_{ac} = \vec{v}_{ab} + \vec{v}_{bc}$

### ٣. یاساکانی نیوتن و هێزی لێکخشاندن (بەشی ٣)
* **یاسای یەکەمی نیوتن (سستی)**: تەن لەسەر باری حەسانەوە یان جووڵەی بەردەوام دەبێت ئەگەر هێزی دەرەکی کاری تێنەکات.
* **یاسای دووەمی نیوتن**: $\Sigma \vec{F} = m\vec{a}$
* **یاسای سێیەمی نیوتن**: $\vec{F}_{12} = -\vec{F}_{21}$
* **کێشکردنی زەوی**: $F_g = mg, \quad g = 9.81\text{ m/s}^2$
* **هاوکۆلکەی وەستاوە لێکخشاندن**: $\mu_s = \frac{F_{s,\text{max}}}{F_n}$
* **هاوکۆلکەی جووڵاوە لێکخشاندن**: $\mu_k = \frac{F_k}{F_n}$
* **هێزی لێکخشاندن**: $F_f = \mu F_n$

### ٤. ئیش، وزە و توانا (بەشی ٤)
* **ئیشی گشتی**: $W_{\text{net}} = F_{\text{net}} d \cos\theta$
* **جووڵە وزە**: $KE = \frac{1}{2}mv^2$
* **پەیوەندی ئیش - جووڵەوزە**: $W_{\text{net}} = \Delta KE = KE_f - KE_i$
* **ماتەوزەی کێشکردن**: $PE_g = mgh$
* **ماتەوزەی جیڕی**: $PE_{\text{elastic}} = \frac{1}{2}kx^2$
* **وزەی میکانیکی و پاراستنی وزە**:
  $$ME = KE + PE \implies ME_i = ME_f$$
* **توانا**: $P = \frac{W}{\Delta t} = F v$

### ٥. تەوژم و بەریەککەوتنەکان (بەشی ٥)
* **تەوژمی بەهێڵ**: $\vec{p} = m\vec{v}$
* **بیردۆزی تەوژم - پاڵ**: $\vec{F}\Delta t = \Delta \vec{p} = m\vec{v}_f - m\vec{v}_i$
* **یاسای پاراستنی تەوژم**:
  $$\vec{p}_i = \vec{p}_f \implies m_1\vec{v}_{1,i} + m_2\vec{v}_{2,i} = m_1\vec{v}_{1,f} + m_2\vec{v}_{2,f}$$
* **بەریەککەوتنی ناچیر (پێکەوەنووسان)**:
  $$m_1\vec{v}_{1,i} + m_2\vec{v}_{2,i} = (m_1 + m_2)\vec{v}_f$$
* **بەریەککەوتنی چیر (پاراستنی جووڵەوزە)**:
  $$\frac{1}{2}m_1 v_{1,i}^2 + \frac{1}{2}m_2 v_{2,i}^2 = \frac{1}{2}m_1 v_{1,f}^2 + \frac{1}{2}m_2 v_{2,f}^2$$

### ٦. هێز و بوارە کارەباییەکان (بەشی ٦)
* **یاسای کۆلۆم**: $F_{\text{electric}} = k_C \frac{\lvert q_1 q_2\rvert}{r^2}$
* **توندی بواری کارەبایی پەیدابوو لە بارگەی خاڵییەوە**: $E = k_C \frac{q}{r^2} = \frac{F}{q}$

### ٧. وزەی کارەبا و تەزووی کارەبایی (بەشی ٧)
* **ماتەوزەی کارەبایی لە بواری ڕێکدا**: $PE_{\text{electric}} = -qEd$
* **جیاوازی ئەڕک (ڤۆڵتیە)**: $\Delta V = \frac{\Delta PE}{q} = -E\Delta d$
* **جیاوازی ئەڕک لە نێوان بارگە خاڵییەکان**: $\Delta V = k_C \frac{q}{r}$
* **بارگەگری**: $C = \frac{Q}{\Delta V}$
* **بارگەگری بارگەگر بە ڕووی هاوتەریب لە بۆشاییدا**: $C = \varepsilon_o \frac{A}{d}$
* **ماتەوزەی کارەبایی هەڵگیراو لە بارگەگردا**:
  $$PE_{\text{electric}} = \frac{1}{2}Q\Delta V = \frac{1}{2}C(\Delta V)^2 = \frac{Q^2}{2C}$$
* **تەزووی کارەبایی**: $I = \frac{\Delta Q}{\Delta t}$
* **بەرگری و یاسای ئۆم**: $R = \frac{\Delta V}{I} = \text{نەگۆڕ}$
* **توانای کارەبایی**: $P = I\Delta V = I^2 R = \frac{(\Delta V)^2}{R}$

### ٨. سووڕە کارەباییەکان و بەرگرییەکان (بەشی ٨)
* **بەستنی دوای یەک (تەوالی)**:
  $$R_{\text{eq}} = R_1 + R_2 + R_3 + \dots$$
  $$I_{\text{total}} = I_1 = I_2 = I_3 = \dots$$
  $$V_{\text{total}} = V_1 + V_2 + V_3 + \dots$$
* **بەستنی هاوڕێک (تەوازی)**:
  $$\frac{1}{R_{\text{eq}}} = \frac{1}{R_1} + \frac{1}{R_2} + \frac{1}{R_3} + \dots$$
  $$V_{\text{total}} = V_1 = V_2 = V_3 = \dots$$
  $$I_{\text{total}} = I_1 + I_2 + I_3 + \dots$$

### پاشکۆی (أ): پێداچوونەوەی بیرکاری و هەڵەکان (Mathematical & Error Analysis Review)
* **زانستی هێماکاری و توانەکان (Scientific Notation & Exponents)**:
  $$10^n \times 10^m = 10^{n+m}, \quad \frac{10^n}{10^m} = 10^{n-m}, \quad (x^n)^m = x^{nm}, \quad x^{1/n} = \sqrt[n]{x}$$
* **کردارە بنچینەییەکان لە کەرتەکاندا (Fractions)**:
  $$\left(\frac{a}{b}\right)\left(\frac{c}{d}\right) = \frac{ac}{bd}, \quad \frac{a/b}{c/d} = \frac{ad}{bc}, \quad \frac{a}{b} \pm \frac{c}{d} = \frac{ad \pm bc}{bd}$$
* **شیتەڵکردن بۆ کۆلکەکان و هاوکێشەی هێڵی ڕاست (Factoring & Linear Equations)**:
  $$(a+b)^2 = a^2 + 2ab + b^2, \quad a^2 - b^2 = (a+b)(a-b)$$
  $$y = ax + b \implies \text{لاری (Slope)} = \frac{\Delta y}{\Delta x} = \frac{y_2 - y_1}{x_2 - x_1} = \tan\theta$$
* **یاساکانی ئەندازە: ڕووبەر و قەبارە (Geometry: Area & Volume)**:
  * لاکێشە: $\text{ڕووبەر} = lw, \quad \text{چێوە} = 2(l+w)$
  * بازنە: $\text{ڕووبەر} = \pi r^2, \quad \text{چێوە} = 2\pi r$
  * سێگۆشە: $\text{ڕووبەر} = \frac{1}{2}bh$
  * گۆ (تۆپ): $\text{ڕووبەری ڕوو} = 4\pi r^2, \quad \text{قەبارە} = \frac{4}{3}\pi r^3$
  * لوولەک: $\text{ڕووبەری لا تەنیشت} = 2\pi rl, \quad \text{قەبارە} = \pi r^2 l$
  * سنوقی لاکێشەیی: $\text{ڕووبەری ڕوو} = 2(lh + lw + hw), \quad \text{قەبارە} = lwh$
* **وردبینی و شیکاری هەڵە لە تاقیکردنەوەدا (Error Analysis in Experiments)**:
  * **هەڵەی پەتی (Absolute Error)**:
    $$\text{هەڵەی پەتی} = |\text{بەهای تاقیکردنەوە} - \text{بەهای پەسەندکراو}|$$
  * **هەڵەی ڕێژەیی (Relative Error)**:
    $$\text{هەڵەی ڕێژەیی} = \frac{|\text{بەهای تاقیکردنەوە} - \text{بەهای پەسەندکراو}|}{\text{بەهای پەسەندکراو}}$$
  * **ڕێژەی سەدی هەڵە (Percentage Error)**:
    $$\text{ڕێژەی سەدی هەڵە} = \text{هەڵەی ڕێژەیی} \times 100\%$$
