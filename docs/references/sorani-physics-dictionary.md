# فەرهەنگی گشتگیر و هێماکانی فیزیا - سۆرانی (CKB)
## Comprehensive Sorani Kurdish Physics Glossary & Symbol Reference

ئەم فەرهەنگە پێکهاتووە لە کۆکراوەی فەرمی و زانستی سەرجەم زاراوە، چەمک، پێناسە و هێما فیزیاییەکان بە زمانی کوردیی ناوەندی (سۆرانی / CKB) بە پێی پرۆگرامی پەروەردەی هەرێمی کوردستان (پۆلەکانی ١٠، ١١، ١٢) و فەرهەنگە ستانداردە زانستییەکان.

---

### بەشی یەکەم: خشتەی گشتگیری زاراوە و پێناسەکان (Terminology & Definitions)

| زاراوەی سۆرانی (Kurdish Term) | English Equivalent | مانا بە عەرەبی (Arabic) | پێناسە و ڕوونکردنەوەی زانستی |
| :--- | :--- | :--- | :--- |
| **لادان** | Displacement | الإزاحة | گۆڕانی ڕاستەوخۆی شوێنی تەن لە نێوان دوو خاڵدا ($\Delta x = x_f - x_i$). |
| **دووری (مەودا)** | Distance | المسافة | تەواوی درێژی ئەو ڕێگەیەی تەنەکە بڕیویەتی. |
| **خێرایی ئاراستەبڕ** | Velocity | السرعة المتجهة | بڕی لادانی تەن لە یەکەی کاتدا ($v = \Delta x / \Delta t$). |
| **تاودان** | Acceleration | التسارع | ڕێژەی گۆڕانی خێرایی بە پێی کات ($a = \Delta v / \Delta t$). |
| **کەوتنی سەربەست** | Free Fall | السقوط الحر | جووڵەی تەنێک لە ژێر کاریگەری تەنها هێزی کێشکردنی زەویدا ($g = -9.81\text{ m/s}^2$). |
| **ئاراستەبڕ (ڤێکتەر)** | Vector | متجه | بڕێک کە خاوەنی بڕ و ئاراستەیە. |
| **بڕی پێوانەیی (سکالەر)** | Scalar | كمية قياسية | بڕێک کە تەنها خاوەنی ژمارە و یەکەیە بێ ئاراستە. |
| **هێز** | Force | القوة | ئەو کاریگەرییەی باری جووڵە یان شێوەی تەن دەگۆڕێت ($F = ma$). |
| **هێزی بەڕەنجام** | Net Force | القوة المحصلة | کۆی ڤێکتەری هەموو ئەو هێزانەی کار لە تەنەکە دەکەن. |
| **هێزی ستوونی** | Normal Force | القوة العمودية | هێزی کاردانەوەی ڕوویەک بە شێوەی ستوونی لەسەر تەنێک ($F_n$). |
| **لێکخشاندن** | Friction | الاحتكاك | هێزی بەرگری لە نێوان دوو ڕووی بەریەککەوتوودا. |
| **سستی (خۆنەگۆڕین)** | Inertia | القصور الذاتي | بەرگری تەنێک لە بەرامبەر گۆڕینی باری جووڵە یان وەستانی (یاسای یەکەمی نیوتن). |
| **هاوسەنگی** | Equilibrium | الاتزان | کاتێک کۆی هێزە کارپێکراوەکان یەکسان بێت بە سفر ($\Sigma \vec{F} = 0$). |
| **تەوژم (زەخم)** | Momentum | الزخم الخطي | بەرهەمی لێکدانی بارستایی لە خێرایی ($\vec{p} = m\vec{v}$). |
| **پاڵدان** | Impulse | الدفع | کاریگەری هێز لە ماوەی کاتدا ($I = F\Delta t = \Delta p$). |
| **کار (ئیش)** | Work | الشغل | گواستنەوەی وزە لە ڕێگەی هێزێک کە لە ئاراستەی لاداندا بێت ($W = Fd\cos\theta$). |
| **وزەی جووڵە** | Kinetic Energy | الطاقة الحركية | ئەو وزەیەی تەنێک بە هۆی خێراییەکەیەوە هەیەتی ($KE = \frac{1}{2}mv^2$). |
| **وزەی شیاو (ماتە)** | Potential Energy | الطاقة الكامنة | ئەو وزەیەی لە تەنێکدا کۆکراوەتەوە بە هۆی شوێنەکەیەوە ($PE = mgh$). |
| **وزەی میکانیکی** | Mechanical Energy | الطاقة الميكانيكية | کۆی وزەی جووڵە و وزەی شیاوی سیستەمێک ($ME = KE + PE$). |
| **توان** | Power | القدرة | ڕێژەی ئەنجامدانی کار لە یەکەی کاتدا ($P = W / \Delta t$). |
| **پاراستنی وزە** | Conservation of Energy | حفظ الطاقة | وزە لە ناو ناچێت و لە نەبوونەوە دروست نابێت، بەڵکو دەگۆڕێت. |
| **بارگەی کارەبایی** | Electric Charge | الشحنة الكهربائية | بارگەی پۆزەتیڤ و نێگەتیڤ بە یەکەی کۆلۆم (C). |
| **یاسای کۆلۆم** | Coulomb's Law | قانون كولوم | هێزی نێوان دوو بارگە: $F = k \frac{\lvert q_1 q_2 \rvert}{r^2}$. |
| **بواری کارەبایی** | Electric Field | المجال الكهربائي | هێزی کارەبایی لەسەر یەکەی بارگەی تاقیکردنەوە ($E = F / q$). |
| **جیاوازی پۆتانسێل** | Potential Difference | فرق الجهد | کار بۆ گواستنەوەی یەکەی بارگە بە یەکەی ڤۆڵت (V). |
| **تەزووی کارەبا** | Electric Current | التيار الكهربائي | ڕێژەی تێپەڕبوونی بارگە بە یەکەی ئەمپێر ($I = Q / t$). |
| **بەرگری کارەبایی** | Resistance | المقاومة الكهربائية | ڕێگری ماددە لە تێپەڕبوونی تەزوو (یاسای ئۆم: $R = V / I$). |
| **سێعەت (بارگەیگری)** | Capacitance | السعة الكهربائية | توانای کۆکردنەوەی بارگە لە بەستەردا ($C = Q / V$). |
| **ئاڵۆگۆڕە موگناتیسکاری** | Mutual inductance | الحث المتبادل | کرداری دروستبوونی پاڵهێزە کارەباییە لە یەکێک لە دووسوڕدا بەهۆی گۆڕانی توندی تەزووی ئەوەکی تردا. |
| **ئاراستەداری ڕووبەر** | Area Vector | متجه المساحة | ئاراستەدارێکە بڕەکەی ڕووبەرە دراوەکەیە و ئاراستەکەشی ستوونە لەسەر ڕووبەرەکە. |
| **ئاواز / جۆری دەنگ** | Timbre | طابع الصوت / نغمة الصوت | ئەو ئاوازەیە کە لە تێکەڵکردنی هارمۆنیە توندی جیاوازەکانەوە پەیدادەبێت. |
| **ئەلیکترۆنی هاوهێزی** | Valence electron | إلكترون التكافؤ | ئەلیکترۆنێکە لە دوورترین چینی دەرەوەی ئاتۆمی گەردیلەدا هەیە. |
| **باسکی خولانەوە** | Lever arm | ذراع القوة / ذراع الرافعة | دووری ستوونییە لە نێوان تەوەرەی خولانەوەو ڕاستەهێڵی کێشراو لەسەر درێژکراوەی هێزەکە. |
| **پەستاوتن** | Compression | الانضغاط / التضاغط | ئەو ناوچەیەیە لە شەپۆلی درێژەدا کە پەستان تێیدا دەگاتە گەورەترین بڕ. |
| **پلەی دەنگ** | Pitch | طبقة الصوت / حدة الصوت | شوێنری ڕادەی تیژی یان گڕی دەنگی بیستراوە، بەپێی لەرەلەری شەپۆلە دەنگییەکەیە. |
| **پپ (لووتکە / تروپک)** | Crest | القمة | ئەو خاڵەیە کە گەورەترین لادانی پۆزەتیڤ/نیگەتیڤی لە شوێنی هاوسەنگبوونەوە هەیە. |
| **بنەمای سەریەککەوتنی شەپۆلەکان** | Superposition principle | مبدأ التراكب الموجي | کاتێک دوو شەپۆل یان زیاتر لە ناوەندێکدا بەیکدەگەن، لادانی تەنوڵکەکانی ناوەندەکە یەکسان دەبێت بە کۆی ئەو دوولادانەی کە هەریکە لە دوو شەپۆلەکەوە پەیدادەبێت. |
| **دەستتێوەردانی دروستکەر (بەریەککەوتنی دروستکەر)** | Constructive interference | التداخل البناء | ئەو بەریەککەوتنەیە کە ڕوودەدات لەکاتی بەیکگەیشتنی لادانەکانی ئەو تەنوڵکانەی ناوەندەکە کە دەکەونە یەک لا لە شوێنی هاوسەنگ بوونەوە بۆ پێکهێنانی لادانێکی بەرهەنجامی گەورەتر. |
| **دەستتێوەردانی لەناوچوو (بەریەککەوتنی لەناوچوو)** | Destructive interference | التداخل الهدام | ئەو بەریەککەوتنەیە کە ڕوودەدات لەکاتی بەیکگەیشتنی لادانی دژ بە یەکەکانی تەنوڵکەیەک لە ناوەندێک و تێیدا فراوانی شەپۆلی بەرهەمهاتوو کەمترە. |
| **بواری موگناتیسی** | Magnetic Field | المجال المغناطيسي | ناوچەیەکە دەتوانرێت تێیدا هێزی موگناتیسی بتوانێت بپێورێت. |
| **بەرگری پوخت** | Pure resistance | المقاومة الصرفة | بەرگرییەکە خودموگناتیسکاری نییە (L = 0). |
| **بەربەستە موگناتیسکاری (ماتە موگناتیسی)** | Inductive impedance | الممانعة الحثية | ڕێژەی نێوان گەورەترین بڕی جیاوازی ئەرکی دەوری دوو جەمسەری موگناتیسبارگیکی پوخته بۆ گەورەترین نرخی تەزووی تێپەڕبوو بەپێیدا لەسوڕی تەزووی گۆڕاوەدا. |
| **باری زەمینی گەردیلە** | Ground state | الحالة الأرضية للذرة | باری نزمترین وزەیە بۆ سیستمێکی بەرپێکراو. |
| **باری ورووژاو** | Excited state | حالة الإثارة / التهيج | بارێکە گەردیلە تێیدا لەباری زەمینیدا نییە. |
| **کریستاڵی دووانی (دایۆد)** | Diode | الدايود / الثنائي البلوري | دەزگایەکی ئەلیکترۆنییە ڕێگا بە تێپەڕ بوونی تەزوو بە ئاراستەیەک دەدات بە بەراورد لەگەڵ ئاراستەکەی تر. |
| **بە خڵتەکردن (دۆپینگ)** | Doping | التطعيم / الإشابة | تێکردنی گەردیلە خڵتەیەک لە نیمچە گەیەنەرێکدا. |
| **پلەی برژۆڵە (پلەی ڕووناکی)** | Order number | رتبة الهدب | ژمارەی برژۆڵەکە بەپێی برژۆڵەی ڕووناكی ناوەند. |
| **پابەندە ئیش (نەخشی کار)** | Work function | دالة الشغل | کەمتەرین وزەی پێویستە بۆ جیاکردنەوەی ئەلیکترۆنێک لە ڕووی کانزاکە. |
| **توندی شەپۆل** | Wave intensity | شدة الموجة | تێکڕای کاتی تێپەڕبوونی وزەیە بەناو یەکەی ڕووبەری ستوون لەسەر ئاراستەی جووڵەی شەپۆلەکە. |
| **تەزووی گۆڕاو** | Alternating current | التيار المتردد / المتناوب | تەزوویەکی کارەباییە کە بڕ و ئاراستەکەی لە کاتە یەکسانەکاندا دەگۆڕێت. |
| **تەزووی هاندراو (موگناتیسکار)** | Induced current | التيار الحثي / المتولد بالحث | تەزووی کارەبایی پەیدابووە لە سوڕێکی کارەبایی داخراودا بە هۆی گۆڕینی لێشاوی موگناتیسی دەوروبەرەوە. |
| **ترانسفۆرمەر (گۆڕەری ڤۆڵتیە)** | Transformer | المحول الكهربائي | دەزگایەکە پاڵهێزی کارەبای موگناتیسکاری تەزووی گۆڕاو بەرز یان نزم دەکاتەوە. |
| **ترانزیستەر** | Transistor | الترانزستور | دەزگایەکە سێ تەلی گەیاندنی هەیە و دەتوانێت نیشانە گەورە بکات. |
| **تیشکدانی کارۆموگناتیسی** | Electromagnetic radiation | الإشعاع الكهرومغناطيسي | گواستنەوەی وزەیە لە ڕێگەی بواری کارەبایی و بواری موگناتیسی کە بە خێرایی ڕووناکی بڵاودەبێتەوە. |
| **تیشکدانی تەنی ڕەش** | Blackbody radiation | إشعاع الجسم الأسود | ئەو تیشکدانەی کە لە تەنی ڕەشەوە دەرچێت، کە بە شێوەیەکی نموونەیی تیشکدەدرێن و دەمژرێن و بەتەنها بەندە لەسەر پلەی گەرمی. |
| **جیاوازی ڕێڕەو** | Path difference | فرق المسار | جیاوازی نێوان ئەو دوو دوورییەی کە دوو شەپۆلی دەرچوو لە دوو سەرچاوەوە دەبڕن تا دەگەنە هەمان خاڵ. |
| **چەقی بارستایی** | Center of mass | مركز الكتلة | ئەو خاڵەیە کە دەکرێت هەموو بارستایی تەنەکەی تێدا کۆبکرێتەوە لەکاتی لێکۆڵینەوە لە جووڵەی جێگۆڕکێدا. |
| **چەقە تاودان (تاودانی ناوەندی)** | Centripetal acceleration | التسارع المركزي | تێکڕای کاتی گۆڕان لە ئاراستەی خێرایی تەنێکدا لەسەر ڕێڕەوێکی بازنەییدا. |
| **خود موگناتیسکاری (خۆهاندان)** | Self induction | الحث الذاتي | پەیدابوونی پاڵهێزی کارەبای موگناتیسکارە لە کۆئێلێکدا بەهۆی گۆڕانی توندی تەزووەکەی ناوەیەوە. |
| **ڕادیان** | Radian | الراديان (زاوية نصف قطرية) | چەقە گۆشەیەک کە درێژی کەوانەکەی یەکسانە بە نیوەتیرەی بازنەکەی، بە پلە بە نزیکەیی دەکاتە 57.3°. |
| **زەبری بارنەگۆڕی (عەزمی سستی)** | Moment of inertia | عزم القصور الذاتي | بڕی بەرەنگاری تەنە بۆ هەر گۆڕانێک لە جووڵەی خولانەوەیدا. |
| **زنجیرە هارمۆنییەکان** | Harmonic series | السلسلة التوافقية | زنجیرەیەک لە لەرەلەرەکان، لەرەلەری بنەڕەتی و چەند جارەکانی دەگرێتەوە. |
| **زرنگانەوە (دەنگدانەوە / رەنین)** | Resonance | الرنين | دیاردەیەکە کاتێک ڕوودەدات کە لەرەلەری سیستمێک یەکسان دەبێت بە لەرەلەری سروشتی ئەو هێزەی کاری تێدەکات. |
| **فراوانی (ئەمپلیتود)** | Amplitude | السعة الموجية / الاتساع | گەورەترین لادان لە شوێنی هاوسەنگبوونەوە. |
| **فۆتۆن** | Photon | الفوتون | کەمترین بڕی وزەی کارۆموگناتیسی سەربەخۆیە لە گەردووندا وە بارستاییەکەی سفرە. |
| **قۆڵ (ناوەندی گرێ)** | Antinode | البطن (في الموجة الموقوفة) | خاڵێکە لە شەپۆلی وەستاودا دەکەوێتە ناوەڕاستی دووری نێوان دوو گرێ، تێیدا فراوانی دەگاتە ئەوپەڕی. |
| **هاندانی کارۆموگناتیسی** | Electromagnetic induction | الحث الكهرومغناطيسي | کرداری بەرهەمهێنانی تەزووی کارەبایی لە گەیەنەرێکدا بەهۆی گۆڕینی لێشاوی موگناتیسی دەوروبەریەوە. |
| **شەپۆلی وەستاو (موقوف)** | Standing wave | الموجة الموقوفة / الساكنة | جۆرێکی شەپۆلە لە بەریەککەوتنی دوو شەپۆل پەیدادەبێت کە هەمان لەرەلەر و درێژی شەپۆل و فراوانییان هەبێت بە دوو ئاڕاستەی پێچەوانە. |
| **کەلێنە گۆرزە (کەلێنی وزە)** | Band gap | فجوة الطاقة | مەودایەکی وزەیە کە بەرزترین گۆرزەی وزەی پڕ لە ئەلیکترۆن و نزمترین گۆرزەی بێ ئەلیکترۆن لەیەکتر جیا دەکاتەوە. |
| **کون (لە نیمچەگەیەنەردا)** | Hole | الفجوة (في أشباه الموصلات) | ئاستە وزەیەکە لە نیمچە گەیەنەردا کە ئەلیکترۆنی تێدا نییە. |
| **کاتە لەرە (خولی لەرینەوە)** | Period | الزمن الدوري | کاتی پێویست بۆ ئەنجامدانی لەرەیەکی (خولێکی) تەواو. |
| **گرێ (لە شەپۆلی وەستاودا)** | Node | العقدة (في الموجة الموقوفة) | خاڵێکە لە شەپۆلی وەستاودا کە هەمیشە تێیدا بەریەککەوتنی لەناوبەری تەواو ڕوودەدات و نەجووڵاوە. |
| **گۆشە لادان** | Angular displacement | الإزاحة الزاوية | گۆشەی خولانەوەی خاڵێک یان تەنێک بە دەوری تەوەرەیەکی جێگیردا. |
| **گۆشە تاودان** | Angular acceleration | التسارع الزاوي | تێکڕای کاتی گۆڕانی گۆشە خێراییە. |
| **گۆشە تەوژم** | Angular momentum | الزخم الزاوي | ئەنجامی لێکدانی زەبری بارنەگۆڕی تەنێک لە گۆشە خێراییەکەی بە دەوری هەمان تەوەرە. |
| **نرخی کاریگەری تەزوو** | Effective current | التيار الفعال | نرخێکی تەزووی گۆڕاوە کە هەمان کاریگەری گەرمی تەزوویەکی نەگۆڕ لە هەمان کاتدا پەیدا دەکات. |
| **ناوەند (ناوەندی بڵاوبوونەوە)** | Medium | الوسط المادي | ئەو ماددەیەی کە شەپۆلەکان تێیدا گوزەر دەکەن. |
| **هاوکۆلکەی یۆنگ** | Young's Modulus | معامل يونغ | بریتییە لە ڕێژەی نێوان فشار بۆ جیفشار لە ماددەیەکی دیاریکراودا. |
| **هاوسەنگی گەرمی** | Thermal Equilibrium | الاتزان الحراري | ئەو بارەیە کە پلەی گەرمی دوو تەن تێیدا یەکسان بن و هیچ وزەیەکی گەرمی ئاڵۆگۆڕ نەکرێت. |
| **هاوکۆلکەی شکانەوەی ناوەند** | Index Of Refraction | معامل الانكسار | بریتییە لە ڕێژەی نێوان خێرایی ڕووناکی لە بۆشاییدا بۆ خێراییەکەی لە ناوەندێکی ڕووندا. |
| **هاوێنە** | Lens | العدسة | تەنی ڕوون کە تیشکی ڕووناکی دەشکێنێتەوە بۆ دروستکردنی وێنە. |
| **هاودیاری (پێکەوەبەستراوی شەپۆلەکان)** | Coherence | التشاكه الموجي | نەگۆڕانی جیاوازی فاز (ڕوخسار) لە نێوان دوو شەپۆل یان زیاتردا. |
| **هێزی کێشکردنی گەردوونی** | Gravitational Force | قوة التجاذب الكتلي / الجاذبية | هێزی کێشکردنی ئاڵۆگۆڕە لە نێوان هەموو دوو تەنێک لە گەردووندا. |
| **هاوکۆلکەی خۆموگناتیسکاری** | Coefficient of Self induction | معامل الحث الذاتي | ڕێژەی نێوان هێزی دژە کارەبایی موگناتیسی بۆ تێکڕای کاتی گۆڕانی توندی تەزوو. |
| **وردی (ڕێکی لە پێوانەدا)** | Accuracy | الدقة / الصحة في القياس | ڕادەی نزیکی نرخی بڕاوە لە نرخە ڕاستەقینەکەی ئەو بڕەی کە دەمانەوێت بیپێوین. |
| **وزەی ناوەکی** | Internal Energy | الطاقة الداخلية | ئەو وزەیەیە کە لە جووڵەی هەڕەمەکی تەنوڵکەکانی ماددەوە پەیدادەبێت، وە دەکاتە کۆی وزەی هەموو تەنوڵکەکان. |
| **وێنەی خەیاڵی** | Virtual Image | الصورة التقديرية / الخيالية | وێنەیەکە کە لە خاڵێکدا دروست دەبێت لەوە دەچێت کە تیشکەکان لێوەی هاتبێتن بەڵام لە ڕاستیدا تەنها درێژکراوەی تیشکەکانن. |
| **وێنەی ڕاستەقینە** | Real Image | الصورة الحقيقية | ئەو وێنەیەیە کە لە ئەنجامی کۆبوونەوەی تیشکە شکاوان یان دراوەکان پەیدا دەبێت و دەتوانرێت لەسەر پەردە وەربگیرێت. |
| **وێڵە تەزووەکان (تەزووی گێژاوی)** | Eddy currents | التيارات الدوامية | ئەو تەزووە موگناتیسیانەن کە لەناو پارچە کانزاکاندا لە کاتی گۆڕانی بواری موگناتیسیدا پەیدادەبن. |
