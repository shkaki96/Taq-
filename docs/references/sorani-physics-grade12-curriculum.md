## Physics Grade 12 Complete Curriculum Reference - Kurdistan Region

**سەرچاوەی فەرمی**: کتێبی فەرمیی فیزیا بۆ پۆلی دوازدەهەمی زانستی (وەزارەتی پەروەردەی حکومەتی هەرێمی کوردستان - چاپخانەی وەزارەت).

## بەشی دووەم: یاسا، هاوکێشە و پەیوەندییە بیرکارییە فەرمییەکان

### ١. هاوکێشەکانی جووڵەی بە خول و کێشکردن (بەشی ١)
* **گۆشە لادان**: $\theta = \frac{s}{r}, \quad \Delta\theta = \frac{\Delta s}{r}$
* **گۆشە خێرایی و گۆشە تاودان**:
  $$\omega_{\text{avg}} = \frac{\Delta\theta}{\Delta t}, \quad \alpha_{\text{avg}} = \frac{\Delta\omega}{\Delta t}$$
* **هاوکێشەکانی جووڵەی بەخول بە گۆشە تاودانی نەگۆڕ**:
  $$\omega_f = \omega_i + \alpha \Delta t$$
  $$\Delta\theta = \omega_i \Delta t + \frac{1}{2}\alpha (\Delta t)^2$$
  $$\omega_f^2 = \omega_i^2 + 2\alpha (\Delta\theta)$$
  $$\Delta\theta = \frac{1}{2}(\omega_i + \omega_f)\Delta t$$
* **پەیوەندیی نێوان بڕە هێڵییەکان و گۆشەییەکان**:
  $$v_t = r\omega, \quad a_t = r\alpha$$
* **چەقە تاودان و چەقە هێز**:
  $$a_c = \frac{v_t^2}{r} = r\omega^2, \quad F_c = m a_c = m \frac{v_t^2}{r} = m r \omega^2$$
* **تاودانی گشتی**: $a = \sqrt{a_t^2 + a_c^2}, \quad \theta = \tan^{-1}\left(\frac{a_c}{a_t}\right)$
* **یاسای کێشکردنی گشتیی نیوتن**: $F_g = G \frac{m_1 m_2}{r^2}, \quad g = G \frac{M_E}{R_E^2} = 9.81\text{ m/s}^2$
* **خێرایی و کاتی خولی هەسارە و مانگە دەستکردەکان**:
  $$v = \sqrt{\frac{GM}{r}}, \quad T = 2\pi\sqrt{\frac{r^3}{GM}}$$

### ٢. هاوکێشەکانی هاوسەنگ بوون و داینەمیکی بەخول (بەشی ٢)
* **زەبر**: $\tau = F d \sin\theta = F \cdot (\text{باسکی خولانەوە})$
* **مەرجەکانی هاوسەنگی**: $\Sigma \vec{F} = 0 \quad (\Sigma F_x = 0, \Sigma F_y = 0), \quad \Sigma \tau = 0$
* **یاسای دووەمی نیوتن بۆ خولانەوە**: $\Sigma \tau = I\alpha$
* **گۆشە تەوژم و پاراستنی**: $L = I\omega, \quad I_i \omega_i = I_f \omega_f$
* **جووڵە وزەی بەخول و پاراستنی وزە**:
  $$KE_{\text{rot}} = \frac{1}{2}I\omega^2$$
  $$ME = \frac{1}{2}mv^2 + \frac{1}{2}I\omega^2 + mgh = \text{نەگۆڕ}$$

### ٣. هاوکێشەکانی لەرینەوە و شەپۆلەکان (بەشی ٣)
* **یاسای هۆک**: $F_{\text{elast}} = -kx$
* **لەرەلەر و کاتەلەرە**: $f = \frac{1}{T}, \quad T = \frac{1}{f}$
* **کاتەلەرەی بەندۆڵی سادە**: $T = 2\pi\sqrt{\frac{L}{a_g}}$
* **کاتەلەرەی سیستەمی بارستایی-سپڕینگ**: $T = 2\pi\sqrt{\frac{m}{k}}$
* **خێرایی شەپۆل**: $v = f\lambda = \frac{\lambda}{T}$
* **درێژی شەپۆلی وەستاو لە پەتدا**: $\lambda = \frac{2L}{A} \quad (A = N - 1)$

### ٤. هاوکێشەکانی دەنگ (بەشی ٤)
* **دیاردەی دۆپلەر**: $f' = f \left(\frac{v \pm v_o}{v \mp v_s}\right)$
* **توندی دەنگ**: $I = \frac{P}{4\pi r^2}$
* **ئاستی توندی دەنگ (دێسیبێڵ)**: $\beta = 10\log\left(\frac{I}{I_o}\right) \quad (I_o = 1.0 \times 10^{-12}\text{ W/m}^2)$
* **ئاوازە هارمۆنییەکان لە بۆریی کراوە**: $f_n = n \frac{v}{2L} \quad (n = 1, 2, 3, \dots)$
* **ئاوازە هارمۆنییەکان لە بۆریی داخراو**: $f_n = n \frac{v}{4L} \quad (n = 1, 3, 5, \dots)$

### ٥. هاوکێشەکانی موگناتیسی (بەشی ٥)
* **لێشاوی موگناتیسی**: $\Phi = B A \cos\theta$
* **بواری موگناتیسیی تەلی ڕاست**: $B = \frac{\mu_o I}{2\pi d}$
* **بواری موگناتیسی لە چەقی کۆیلەی بازنەییدا**: $B = \frac{\mu_o N I}{2r}$
* **بواری موگناتیسیی کۆیلەی لولپێچ**: $B = \frac{\mu_o N I}{\ell} = \mu_o n I$
* **هێزی موگناتیسی لەسەر بارگەی جووڵاو**: $F = q v B \sin\theta$
* **هێزی موگناتیسی لەسەر تەلی هەڵگری تەزوو**: $F = B I \ell \sin\theta$

### ٦. هاوکێشەکانی کارۆموگناتیسی و AC (بەشی ٦)
* **پاڵهێزی هاندراو لە تەلی جووڵاودا**: $\varepsilon = B\ell v$
* **یاسای فارادای**: $\varepsilon = -N \frac{\Delta\Phi}{\Delta t} = -N \frac{\Delta(BA\cos\theta)}{\Delta t}$
* **خودموگناتیسکاری**: $\varepsilon = -L \frac{\Delta I}{\Delta t}, \quad L = \frac{\mu_o N^2 A}{\ell}$
* **ئاڵۆگۆڕە موگناتیسکاری**: $\varepsilon_2 = -M \frac{\Delta I_1}{\Delta t}$
* **دینەمۆی AC**: $\varepsilon = NAB\omega \sin(\omega t), \quad \varepsilon_m = NAB\omega$
* **بەها کاریگەرەکانی تەزوو و ڤۆڵتیە**: $I_e = \frac{I_m}{\sqrt{2}} \approx 0.707 I_m, \quad V_e = \frac{V_m}{\sqrt{2}} \approx 0.707 V_m$
* **توان لە سووڕی AC**: $P = I_e^2 R = \frac{1}{2} I_m^2 R$
* **بەربەستەی موگناتیسکاری و بارگەگری**: $X_L = \omega L = 2\pi f L, \quad X_C = \frac{1}{\omega C} = \frac{1}{2\pi f C}$
* **بەربەستەی گشتی (Impedance)**: $Z = \sqrt{R^2 + (X_L - X_C)^2}, \quad I_e = \frac{V_e}{Z}, \quad \tan\theta = \frac{X_L - X_C}{R}$
* **لەرەلەری زرنگانەوە (Resonance)**: $f_{\text{res}} = \frac{1}{2\pi\sqrt{LC}}$
* **هاوکێشەی ترانسفۆرمەر**: $\frac{V_2}{V_1} = \frac{N_2}{N_1}, \quad \frac{I_1}{I_2} = \frac{N_2}{N_1}$

### ٧. هاوکێشەکانی بەریەکداچوون، فیزیای ئەتۆمی و ئەلیکترۆنیکس (بەشەکانی ٧، ٨، ٩)
* **دەستتێوەردانی دروستکەر و لەناوبەر**:
  $$d\sin\theta = m\lambda \quad (\text{ڕووناک}), \quad d\sin\theta = \left(m+\frac{1}{2}\right)\lambda \quad (\text{تاریک})$$
* **فۆتۆن و بەبڕبوونی وزە**: $E = hf = \frac{hc}{\lambda}$
* **هاوکێشەی کارۆڕووناکی**: $KE_m = hf - \Phi = hf - hf_o$
* **لادانی کۆمپتن**: $\Delta\lambda = \lambda' - \lambda = \frac{h}{m_e c}(1 - \cos\phi)$
* **مەرجی لەرەلەری بۆر**: $hf = E_f - E_i$
* **قازانجی تەزووی ترانزستەر**: $\beta = \frac{I_c}{I_b}, \quad I_e = I_b + I_c$

## بەشی سێیەم: پاشکۆکانی بیرکاری، هێماکان، یەکەکان و نەگۆڕەکان

### پاشکۆی (أ): پێداچوونەوەی بیرکاری و هەڵەکان (Math Review)
* **هەڵەی پەتی (Absolute Error)**:
  $$\text{هەڵەی پەتی} = \lvert \text{نرخی تاقیکراوە} - \text{نرخی پەسەندکراو}\rvert$$
* **هەڵەی ڕێژەیی (Relative Error)**:
  $$\text{هەڵەی ڕێژەیی} = \frac{\lvert \text{نرخی تاقیکراوە} - \text{نرخی پەسەندکراو}\rvert}{\text{نرخی پەسەندکراو}}$$
* **ڕێژەی سەدی هەڵە (Percentage Error)**:
  $$\text{ڕێژەی سەدی هەڵە} = \text{هەڵەی ڕێژەیی} \times 100\%$$
* **ڕێساکانی توان**: $x^n \cdot x^m = x^{n+m}, \quad \frac{x^n}{x^m} = x^{n-m}, \quad (x^n)^m = x^{nm}, \quad x^{1/n} = \sqrt[n]{x}, \quad x^0 = 1$
* **هاوکێشەی هێڵی ڕاست**: $y = ax + b, \quad a = \text{لاری} = \frac{\Delta y}{\Delta x} = \tan\theta$
* **هاوکێشەی فیساگۆرس و سێگۆشەزانی**: $c^2 = a^2 + b^2, \quad \sin\theta = \frac{a}{c}, \quad \cos\theta = \frac{b}{c}, \quad \tan\theta = \frac{a}{b}, \quad \sin^2\theta + \cos^2\theta = 1$
